### Versioning

Release tags and `manifest.json` use the same canonical version. Alpha prereleases use `YYYY.M.RRaXX` (for example `2026.8.01a01`), beta prereleases use `YYYY.M.RR-betaXX`, and stable releases use `YYYY.M.RR`.
