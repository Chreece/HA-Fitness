# Fitness 2026.8.0-beta.13

Adds a per-profile Fitness language setting.

- Setup preselects Home Assistant's UI language when supported.
- Unsupported UI languages default to English.
- Language can be changed later from Profile options.
- Available choices are exactly the languages already localized by Fitness.
- Static announcements/coaching and AI output instructions use the selected
  profile language.
- Existing profiles remain backward-compatible.
